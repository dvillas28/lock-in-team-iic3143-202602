# LMS UI UX

Use for product screens and interaction design in the LMS.

Priorities:
- Student flows optimize for finding work, submitting on time, and seeing feedback.
- Teacher flows optimize for setup, correction, publication, and grade review.
- Admin flows optimize for tenant, course, section, and user management.
- Make status, deadlines, submission state, and grade visibility explicit.
- Meet basic accessibility: keyboard access, visible focus, labels, contrast, and responsive text.
- Use real domain content in UI checks; placeholder-only screens hide workflow issues.
