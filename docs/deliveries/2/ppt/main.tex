\small Render: app/API/PostgreSQL, según Blueprint existente al corte.
Pool pg interno; HAProxy/HA/PgBouncer externo diferidos por falta de necesidad medida.
\begin{itemize}
\item Free: arranque en frío, cuota y expiración de DB; sin promesa de backups/PITR.
\item Binarios/object storage fuera del MVP markdown.
\item Configuración no acredita despliegue: sin verificación remota en el polish.
\end{itemize}
\end{frame}
\begin{frame}{Preguntas de falla: límites actuales}
\small
\begin{itemize}
\item Sin réplicas declaradas: caída de app/API interrumpe servicio; revisar readiness y corregir.
\item Sin HA de PostgreSQL: recuperación requiere operación y respaldo comprobado.
\item Free tiene suspensión/cuota/expiración: no se promete continuidad ni PITR.
\item HAProxy, pooling externo y failover requieren métricas, presupuesto y otra misión.
\item RLS y permisos protegen aislamiento; no resuelven disponibilidad.
\end{itemize}
\end{frame}
\begin{frame}{Multi-tenancy lógico}
\begin{itemize}
\item User global; Membership activa habilita institución.
\item is\_admin e is\_super\_admin independientes de Enrollment.
\item Enrollment.role: teacher, student o assistant por sección (varchar+CHECK).
\item Ruta singular /api/v1/institution/\{slug\}/... solicita contexto, no autoriza.
\item FK compuestas, permisos y RLS con runtime sin bypass; sin base por tenant.
\end{itemize}
\end{frame}

\begin{frame}{Cuentas y atribución (E6)}
\small
\begin{itemize}
\item Bootstrap: UC/UTFSM, diez cuentas; solo superadmins reciben ambos flags.
\item Etiquetas teacher/assistant/student no crean Enrollment; seed académico separado.
\item Operador provisiona institución/identidad inicial. No hay alta general/invitaciones.
\item Replay conserva IDs, hashes, estados y revocaciones; secretos fuera de entregables.
\item Corte 2026-10-29, 7f4334a: roles/creación/delegación/RLS/provisión ya existían.
\item Polish documenta/valida; fix funcional nuevo: privacidad de auditoría grade.
\item F6/G6 positivos conservados; sin atribución retroactiva ni despliegue nuevo.
\end{itemize}
\end{frame}
