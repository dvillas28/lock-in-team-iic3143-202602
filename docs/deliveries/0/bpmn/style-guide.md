# Estilo de los modelos BPMN

Preferencia del usuario: **estilo neutro para informe académico**.

| Token | Valor |
| --- | --- |
| Papel | `#fafaf8` |
| Tareas y área de trabajo | `#ffffff` |
| Tinta y conectores | `#202020` |
| Texto secundario | `#505050` |
| Separadores | `#a8a8a4` |
| Cabecera de participante | `#e9e9e5` |
| Cabecera de carril | `#f0f0ec` |
| Título | Liberation Serif, 40 px |
| Actividades y reglas | Liberation Sans, 20 px |
| Carriles, decisiones, eventos y leyenda | Liberation Sans, 16 px |

Las fuentes locales se verifican antes de exportar, para producir PNG sin dependencia de fuentes remotas. La semántica se expresa mediante símbolos, texto y carriles, sin depender del color. Los originales HTML incluyen título y descripción accesibles en el SVG. Tamaño adaptado al contenido (`fit`), 1760 px de ancho lógico y exportación a escala 2.
