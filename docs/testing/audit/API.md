## Reglas transversales verificadas en código

AuthGuard global salvo health/ready/login; TenantGuard solo normaliza path; withInstitution hace membership real.
GET privados no-store. Endpoints académicos de main agregan nosniff/no-store y exigen JSON si hay body.
400 UUID/slug/shape, 401 identidad, 404 tenant/recurso invisible, 403 acción sobre recurso visible.
No existen DELETE, refresh, logout, upload/download, alta general users/institutions ni corrección manual.
Códigos413/415 pueden resultar del parser global incluso sin declaración por operación; ver D09 y errores.
Controles SQL directos y CLI onboarding/superadmin no son endpoints y se catalogan O.
CORS OPTIONS es infraestructura, no una operación OpenAPI; probar preflight real en entorno institucional.
Listado quiz no pagina; institutions/courses/sections/modules/materials son colecciones completas según servicio.
Paginan memberships/users/enrollments/attempts/book/audit: default20 max100 y cursor scope específico.
